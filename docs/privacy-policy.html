Política de Privacidad de Equi Harmony Monitor

Última actualización: 10 de septiembre de 2026

Equi Harmony Monitor ("la aplicación") es una app para propietarios, veterinarios y responsables de establos, usada para gestionar perfiles de caballos, historial clínico, monitoreo ambiental y comunicación interna. Esta política explica qué datos recopilamos y cómo los usamos.

Datos que recopilamos

  • Cuenta: correo electrónico y contraseña (gestionados de forma segura por Supabase Auth) para identificar a cada usuario y su rol (propietario, veterinario, administrador del establo).
  • Perfiles: nombre, datos del caballo, fotografías subidas por el usuario, plan de medicación e historial clínico ingresado manualmente.
  • Fotografías: imágenes que el usuario decide subir a su perfil o al muro de publicaciones; se almacenan en un bucket privado/público de Supabase Storage.
  • Mensajes de chat: texto enviado entre usuarios de un mismo establo, almacenado en la base de datos para permitir la comunicación en tiempo real.
  • Notificaciones push: un token de dispositivo (Firebase Cloud Messaging) para poder enviar avisos de medicación o alertas de sensores.

Cómo usamos los datos

Los datos se usan únicamente para el funcionamiento de la aplicación: mostrar perfiles, gestionar aprobaciones de administradores, enviar notificaciones y permitir el chat entre usuarios del mismo establo. No vendemos ni compartimos datos con terceros para fines publicitarios.

Dónde se almacenan los datos

Los datos se guardan en servidores de Supabase (base de datos y almacenamiento) y en Firebase (mensajería push), ambos proveedores con sus propias políticas de seguridad.

Tus derechos

Puedes solicitar la eliminación de tu cuenta y de los datos asociados escribiendo al contacto indicado abajo. El administrador principal del establo también puede aprobar o eliminar cuentas de usuario desde el panel de gestión.

Menores de edad

La aplicación no está dirigida a menores de 13 años y no recopila intencionalmente datos de menores.
